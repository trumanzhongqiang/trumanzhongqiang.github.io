# 原创音乐 Skill：从一句情绪到一首完整的歌

音乐创作不该只属于专业音乐人。普通人说不清「BPM 和调式」，但说得出「心碎但倔强」。这个 Agent Skill 接收一句情绪描述，走完一条完整的 AI 音乐创作链路：歌词 → 曲风提示词 → MV 概念 → 分镜 → 首尾帧与视频提示词——本地装有 Suno CLI 等工具时，还能直接生成出音频与视频素材。

**GitHub 仓库**：[trumanzhongqiang/music-skill](https://github.com/trumanzhongqiang/music-skill) ｜ 当前版本 v1.3.0 ｜ MIT 开源

## 它是怎么工作的

```
情绪描述
  → 情绪解析与风格锚定（情绪对 / 核心意象 / 能量曲线 / 锚定句）
  → 歌词（押韵纪律 + 演唱形式设计 + 发音校正）
  → 曲风提示词（五要素 + 排除风格，16 套流派模板）
  → MV 概念 → 分镜脚本 → 首尾帧提示词 → 视频提示词
  → 可选：调用本地生成工具直接产出成品
```

- **情绪是起点**：只需描述一种情绪或一个故事，无需任何音乐术语
- **一条龙但可分步**：可以跑完全程，也可以只要歌词、只要 MV，各阶段产物自包含
- **中文创作专项**：内置中文韵脚库（开口韵/闭口韵选型、副歌 Hook 写法），押韵纪律精确到「副歌句句押、主歌可松散」
- **防 Suno 唱错字**：交付前按发音指南扫多音字、阿拉伯数字、生僻英文——「还」唱成 huán 这种翻车，在写词阶段就消灭

## 关键设计决策

**为什么所有阶段共享一份「情绪内核」？** 没有锚的多阶段生成必然漂移：歌词在下雨、曲风在燃、MV 在文艺，三个产物各说各话。所以阶段 0 先把模糊情绪落成四个可检查字段，后续每个阶段的标题下都必须写明锚定句，质检第一查专门核对各阶段是否跑偏。

**为什么首尾帧只允许「动作发展」一处不同？** 图生视频模型会把帧间差异硬转成形变——人物闪烁、场景跳变。所以 Skill 强制首帧与尾帧的主体、场景、光线、色调逐字一致，风格后缀全片复用，质检里用逐字 diff 审计。

**为什么曲风提示词要写「排除风格」？** 只写「想要什么」不够——不写 `auto-tune`，模型可能默认给你电音处理。每套流派模板都带 exclude 行，从「这类歌最忌讳的处理」倒推。
