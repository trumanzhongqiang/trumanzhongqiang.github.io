# 原创音乐 Skill：从一句情绪到一首完整的歌

音乐创作不该只属于专业音乐人。这个 Agent Skill 接收用户的情绪描述，产出一条完整的 AI 音乐创作链路：歌词、曲风、MV、分镜、视频。

## 它是怎么工作的

用户只需要描述一种情绪或一个故事，比如「夏夜雨后一个人散步的释然」。Skill 会依次生成：

- **歌词**：基于情绪意象创作，控制押韵与结构（主歌/副歌/桥段）
- **曲风提示词**：为 Suno 类音乐生成模型设计风格 Prompt（流派、节奏、配器、人声、情绪曲线）
- **MV 概念设计**：整体视觉风格、色调、叙事主线
- **分镜脚本**：逐镜头的画面描述、景别、运镜
- **首尾帧提示词**：为每个分镜生成首帧/尾帧图像提示词（用于图生视频模型）
- **视频提示词**：首尾帧 + 运动描述，交给视频生成模型产出最终分镜片段

## 设计上的思考

- **情绪是起点**：普通人说不清「BPM 和调式」，但说得出「心碎但倔强」——用情绪语言做输入
- **一条龙但可分步**：可以一键跑完全程，也可以只生成歌词、只设计 MV，随取随用
- **风格一致性**：歌词意象、曲风、MV 视觉共享同一份「情绪内核」，避免各说各话

## 技术实现

基于 Agent Skill 架构：情绪解析 → 多阶段生成流水线（文本→音频提示词→图像提示词→视频提示词），核心是跨阶段的风格锚定与一致性约束。
