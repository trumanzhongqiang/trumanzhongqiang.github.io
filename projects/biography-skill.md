# 个人传记：帮普通人写一本自己的传记

每个人都值得被记录，但传记写作对普通人来说门槛太高。这个 Agent Skill 把「写传记」变成一场自然的对话——用户只需要聊天式地回忆人生，剩下的交给 AI。

## 它是怎么工作的

- **访谈式采集**：像专业传记作者一样，通过有温度的一连串提问，引导用户回忆人生中的重要时刻、关键人物与转折点
- **结构化整理**：自动把零散的回忆按时间线归档，识别主题线索，补全时间、地点、人物关系
- **章节化写作**：将素材组织成连贯的章节，保留用户本人的语言风格和情感色彩，而不是写成干巴巴的流水账

## 设计上的思考

- **低门槛**：不要求用户会写作，会聊天就行
- **渐进式**：支持多次、随时续写，人生很长，传记也可以慢慢写
- **私密性**：所有素材都存在本地，涉及隐私的内容由用户自己掌控

## 技术实现

基于 Agent Skill 架构：访谈策略编排 + 记忆管理 + 长文写作约束。重点解决了长上下文下的素材一致性（前后说法冲突时主动与用户确认）和文风统一问题。
