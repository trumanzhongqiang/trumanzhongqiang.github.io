# 科普漫画 Skill：给自媒体一键生成科普漫画

自媒体科普内容的痛点：文字没人看，漫画不会画。这个 Agent Skill 让创作者只需提供一个科普选题，就能产出一整套可发布的漫画图片——事实准确、角色跨格一致、气泡文字清晰。

**GitHub 仓库**：[trumanzhongqiang/science-comic-skill](https://github.com/trumanzhongqiang/science-comic-skill) ｜ 当前版本 v1.1.0 ｜ MIT 开源

## 它是怎么工作的

```
选题分析 → 事实核查（知识卡，来源可溯）
        → 角色卡锚定（外观/色值/画风固化为锚定词）
        → 分镜脚本（每格一个知识点，先确认再出图）
        → 逐格图像生成（锚定词逐字嵌入每格）
        → 气泡文字后期合成（模型不碰文字）
```

- **选题理解**：提炼核心知识点，规划「悬念开场 → 层层拆解 → 总结升华」的叙事节奏
- **事实核查优先**：写脚本前先检索核对，每个知识点一张知识卡——一句话结论 + 来源 + 画面化建议
- **分镜脚本**：逐格输出画面描述、旁白与气泡对话，每格只讲透一个知识点，先给你确认再出图
- **逐格出图**：每格提示词 = 画风描述词 + 角色锚定词 + 本格画面，多角色同框防混淆
- **智能文字策略**：气泡与标题一律留空，后期精准填字，不错字、可修改

## 关键设计决策

**为什么事实核查先于一切创作？** 漫画越好看传播越广，错误知识被放大得越狠——画面朴素可以救，知识错了救不了。所以核查不通过的知识点一律不进脚本；检索不到依据的说法不写成「科学家认为」式的泛话，点名缺口、把决定权交还给用户。

**为什么角色一致性靠「锚定词逐字复用」？** 图像模型每次出图都是重新想象——不锁定描述，第 3 格的主角和第 1 格就会长成两个人，连载直接崩盘。所以角色卡（外观、具体色值、画风）被压缩成一段锚定提示词，原样嵌入每一格、每一期，一个字都不许改。

**为什么文字一律后期合成？** 图像模型渲染中文必出乱码错字，且无法无痕修复、只能整格重画。让模型只画空白气泡，文字后期填——清晰、可改、可换字体。
