# 科普漫画 Agent Skill：给自媒体一键生成科普漫画

自媒体科普内容的痛点：文字没人看，漫画不会画。这个 Agent Skill 让创作者只需要提供一个科普选题，就能产出一整套可发布的漫画图片。

## 它是怎么工作的

- **选题理解**：接收选题或一段科普文案，自动提炼核心知识点，规划「悬念开场 → 层层拆解 → 总结升华」的叙事节奏
- **脚本与分镜**：生成逐格漫画脚本，每格包含画面描述、旁白文案和气泡对话
- **画风与角色设定**：先固化角色形象（外观、配色、画风描述词），保证同一套漫画里主角跨镜头长相一致
- **图片生成**：逐格产出漫画图片，自动处理多角色构图、表情与肢体动作
- **智能文字策略**：图片模型生成中文文字不可靠，Skill 会预留空白气泡和标题位，由 AI 后期精准填字

## 设计上的思考

- **科学准确性优先**：生成脚本前先检索核对知识点，避免「漫画很好看但知识是错的」
- **角色一致性是生命线**：跨格保持一致靠「角色卡」机制——把角色描述词作为锚点贯穿所有镜头的提示词
- **可批量连载**：同一角色卡可复用到整个系列，做「连载号」时风格不漂移

## 技术实现

基于 Agent Skill 架构：选题分析 → 事实核查 → 分镜脚本 → 角色卡锚定 → 逐格图像生成 → 气泡文字后期合成。
