# 科普漫画 Skill：把一个选题做成一套能看的条漫

自媒体科普的麻烦是：文字没人看完，漫画又不会画。这个 Agent Skill 不是一键出图。它先核查事实，再写分镜，逐格画空白气泡，最后用脚本把中文填上去。

**GitHub**：[trumanzhongqiang/science-comic-skill](https://github.com/trumanzhongqiang/science-comic-skill) ｜ v1.2.0 ｜ MIT

## 它实际怎么做

```
选题 → 事实核查（对不上的来源要取舍）
    → 角色卡（抽象风格 + 具象体型，两级都要写）
    → 分镜确认
    → 一格一个目录、串行出图
    → 脚本定位气泡并填字
    → 四查写进交付说明
```

## 做过才改掉的三条

**锚定词逐字复用，角色仍会漂移。** 只写 “chibi 2-head-tall” 时，第 3 格会变成细长身材，第 5 格会换肤色。后来改成必须写极大圆头、短粗身体和肤色色值。重画时加强这一级，不在旧图上补。

**气泡不是只能写 5 个字。** 5 个字是模型常画的小气泡容量，不是文案上限。现在要求把空白气泡画大，对白写成一句能听懂的话。装不下就换大气泡或改文字卡，字号不缩到看不清。

**文字合成不是“用画图软件点一下”。** 要定位封闭的白区、做中文禁则折行、避开右下角合规水印。脚本随仓库的 `tools/` 一起发。
