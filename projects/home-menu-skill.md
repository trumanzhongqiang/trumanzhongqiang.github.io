# 我的私房菜：帮每个家庭设计自己的菜单

「今天吃什么」是每天都在发生的难题。这个 Agent Skill 不追求推荐网红菜谱，而是帮每个家庭沉淀出属于自己的私房菜单。

## 它是怎么工作的

- **家庭画像**：记录家庭成员的口味偏好、忌口、过敏源、烹饪设备与厨艺水平
- **菜单设计**：按周生成家常菜单，兼顾营养均衡、食材多样性和烹饪时间，工作日快手菜、周末大餐自动区分
- **食材规划**：根据菜单自动生成采购清单，合并同类食材，减少浪费
- **持续进化**：吃完反馈「太咸/孩子不爱吃/下次还想吃」，菜单越用越懂你家的胃

## 设计上的思考

- **家常菜优先**：推荐的是能复刻的普通食材和步骤，不是需要买齐十种调料的「收藏吃灰」菜谱
- **主人翁是用户**：AI 提供方案和 rationale，最终拍板权在家庭主厨
- **烟火气**：会考虑「昨天吃了鸡肉，今天换换口味」这类生活化的连续性感知

## 技术实现

基于 Agent Skill 架构：家庭偏好记忆 + 约束规划（营养、时间、预算）+ 迭代反馈学习。
